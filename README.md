# AdoteUmAmigo

## Descrição
Aplicação web simples para adoção de animais, onde usuários podem ver animais disponíveis, cadastrar anúncios, entrar em contato, etc. 

## Funcionalidades
- Listar animais disponíveis para adoção  
- Permitir cadastro de novos animais por nome, foto, características(incompleto no momento)
- Permitir busca / filtragem (por tipo, etc.)  
- Página de detalhes do animal com informações completas  
- Cadastro e Login

## Tecnologias utilizadas
Liste as tecnologias, frameworks e bibliotecas usados: 
- JavaScript  
- React  
- Vite / Webpack  
- Tailwind CSS 

## Instalação / Como rodar localmente
Passo-a-passo para quem quiser clonar e testar o projeto:  

- git clone https://github.com/guihlherme0/AdoteUmAmigo.git
- cd AdoteUmAmigo
- npm install    # ou yarn install, dependendo
- npm run dev    # ou comando de start equivalente
